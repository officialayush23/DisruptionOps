# Verified against all 66 Python files in app/: zero occurrences of any kind,
# imports or otherwise. The orchestrator is deterministic on purpose — a fixed
# order, one transaction, every step writing an event that names its cause — so
# there was never a graph runtime to install. Declaring them invited a fair
# question about what this project actually is, and the honest answer is better
# than the dependency.

# costs a failed deploy — which is precisely what happened when tenacity was
