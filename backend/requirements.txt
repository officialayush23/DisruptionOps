# Removed, and worth recording why rather than quietly dropping:
#
#   langchain, langchain-core, langgraph, langchain-google-genai, langchain-aws
#       Imported nowhere. The orchestrator is deterministic on purpose — a fixed
#       order, one transaction, every step writing an event that names its cause
#       — so there was never a graph runtime to install. Leaving them declared
#       invited a fair question about what this project actually is, and the
#       honest answer is better than the dependency.
#
#   google-genai, boto3
#       Provider SDKs for models reached over plain HTTP through `httpx`.
#
#   shapely, pyproj
#       Geometry is done in PostGIS, in the database, where the data already is.
#
#   slowapi, prometheus-fastapi-instrumentator, tenacity, orjson
#       Rate limiting is `app/core/ratelimit.py`, retries are in the feed
#       clients, and FastAPI's own JSON encoder was never replaced.
#
# Every line above is imported by code that runs. Re-add anything the moment it
# is actually used, not in anticipation.
